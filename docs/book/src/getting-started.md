# Getting Started

DataSynth generates statistically realistic, fully interconnected enterprise financial data. This section covers installation, running your first generation, and exploring the built-in presets.

## Sections

- [Installation](getting-started/installation.md) -- Building from source, feature flags, and binary location
- [Quick Start](getting-started/quick-start.md) -- Running your first generation in under a minute

## Minimum Requirements

- Rust 1.75+ (2024 edition)
- 512 MB RAM (demo), 2+ GB for large configs
- Linux, macOS, or Windows (WSL recommended)
