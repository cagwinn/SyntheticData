\section{Released Configuration v$1.0$}
\label{sec:appendix:config}

The verbatim YAML below is the configuration that produces the
released v$1.0$ \bench{} dataset.  It is reproduced in
\texttt{configs/examples/bench/vynfi\_net\_v1.yaml} in the
\system{} repository~\citep{datasynth-repo} and is the file the
released archive is generated from.

\begin{lstlisting}[language={},basicstyle=\ttfamily\footnotesize,
                   caption={Released configuration v$1.0$ (excerpt).
                            Full file in
                            \texttt{configs/examples/bench/vynfi\_net\_v1.yaml}.}]
global:
  seed: 42
  period_months: 12
  fiscal_year_start: "2024-01-01"
  industry_profile: manufacturing
  presentation_currency: USD

companies:
  count: 25
  group_structure: enterprise

chart_of_accounts:
  preset: manufacturing
  expand_industry_subaccounts: true

transactions:
  count_per_company_per_month: ~       # set by industry profile

fraud:
  fraud_rate: 0.020
  document_fraud_rate: 0.050
  propagate_to_lines: true

graph_export:
  je_network_csv:
    enabled: true
    methods: [A, B]                    # default; C, D, E disabled
  pytorch_geometric:
    enabled: true
  neo4j:
    enabled: false
  dgl:
    enabled: false

financial_reporting:
  enabled: true                        # produces trial balances
\end{lstlisting}
